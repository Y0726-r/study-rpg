【Q. どこを直せばいいの？】
今後は、あなたのPCにある以下のフォルダ内のファイルを編集してください。
フォルダ: /Users/mitsuki/Desktop/study-rpg-github 3/

■ デザインを変えたい時
編集ファイル: style-retro.css
（色、レイアウト、配置、フォントなど）

■ 文字や構成を変えたい時
編集ファイル: index.html
（画面のタイトル、ボタンの文字、要素の並び順など）

■ 動きやロジックを変えたい時
編集ファイル: script.js
（ガチャの確率、計算式、ボタンを押した時の動作など）

----------------------------------------

【Q. 編集したらどうするの？】
編集して保存した後、以下のコマンドをターミナルで実行すれば、
自動的にGitHub（インターネット）に変更が反映されます。

1. ターミナルを開く
2. 以下のコマンドを順番に入力（コピペ推奨）

cd "/Users/mitsuki/Desktop/study-rpg-github 3"
git add .
git commit -m "更新"
git push

これだけでOKです！
数分待てば、以下のURLに最新の状態が反映されます。

■ 公開URL
https://github.com/Y0726-r/study-rpg

以前のトラブルの原因と対策
========================================

【問題1：画面が真っ白/崩れた】
原因：vercel.json という設定ファイルが誤って含まれており、
CSSファイルの読み込みを邪魔していました。
対策：このファイルは削除したので、今後は心配ありません。

【問題2：GitHubに反映されない】
原因：PCとGitHubの間で更新履歴の食い違い（衝突）が起きていました。
対策：強制更新を行い、現在は完全に一致しています。

今後は上記の「編集」→「git push」の手順だけでスムーズに運用できます。
